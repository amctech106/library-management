# لائبریری مینجمنٹ سسٹم (Library Management System)

یہ ایک تیز ترین اور ہلکا پھلکا آف لائن لائبریری مینجمنٹ سسٹم ہے جسے خاص طور پر مدارس، مساجد اور چھوٹی لائبریریوں کی ضروریات کو مدنظر رکھتے ہوئے تیار کیا گیا ہے۔ اس پروجیکٹ میں خالص اردو ٹائپوگرافی (جمیل نوری نستعلیق) اور ایک بہترین، یوزر فرینڈلی انٹرفیس فراہم کیا گیا ہے۔

## خصوصیات (Features)
* **آف لائن فعالیت:** یہ سسٹم مکمل طور پر براؤزر میں آف لائن کام کرتا ہے، اسے چلانے کے لیے کسی لائیو سرور یا انٹرنیٹ کی ضرورت نہیں۔
* **کتابوں کا نظم:** نئی کتابیں شامل کرنے، ان کی تفصیلات ایڈٹ کرنے، اور حذف کرنے کی مکمل سہولت۔
* **کتابوں کا اجراء (Issue/Return):** طلباء اور اساتذہ کو کتابیں جاری کرنے اور ان کی واپسی کا مکمل ریکارڈ رکھنے کا نظام۔
* **تیز ترین تلاش:** کتاب کے نام، مصنف اور پبلشر کے نام کے ذریعے پلک جھپکتے ہی ڈیٹا بیس سے کتاب تلاش کریں۔
* **محفوظ ڈیٹا:** آپ کا تمام ڈیٹا براؤزر کی مقامی میموری (Local Storage) میں ہمیشہ کے لیے محفوظ رہتا ہے۔
* **ایکسل بیک اپ:** کسی بھی وقت تمام کتابوں کا ریکارڈ ایکسل (CSV) فائل میں ڈاؤنلوڈ کر کے محفوظ کریں۔
* **پرنٹ کی سہولت:** ایک کلک پر موجودہ کتابوں کی فہرست کو باآسانی پرنٹ کریں۔

## ٹیکنالوجیز (Technologies Used)
* **فرنٹ اینڈ:** HTML5, CSS3, Vanilla JavaScript
* **اسٹائلنگ:** Tailwind CSS (ریسپانسیو ڈیزائن کے لیے)
* **آئیکنز:** FontAwesome
* **فونٹ:** جمیل نوری نستعلیق (خوبصورت اردو ڈسپلے کے لیے)

## استعمال کا طریقہ (How to Use)
1. پروجیکٹ کی فائلز ڈاؤنلوڈ کریں اور فولڈر کو Extract کریں۔
2. فولڈر میں موجود `index.html` فائل پر ڈبل کلک کریں، یہ آپ کے ڈیفالٹ براؤزر میں کھل جائے گی۔
3. آپ کا سافٹ ویئر استعمال کے لیے مکمل طور پر تیار ہے! (بہترین نتائج کے لیے گوگل کروم یا مائیکروسافٹ ایج کا استعمال کریں)۔
